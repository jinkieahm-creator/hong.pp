MARVEL UNIVERSE는 마블 시네마틱 유니버스를 하나의 영화 아카이브로 정리한 웹디자인·프론트엔드 포트폴리오 프로젝트입니다.

UNIVERSE

Marvel Cinematic Universe

One Story Told Across Dozens of Films

마블 시네마틱 유니버스(MCU)는 마블 스튜디오가 2008년 「아이언맨」부터 만들어 온 영화 시리즈입니다. 각각의 영화는 독립된 이야기이면서도 같은 세계를 공유해, 한 영화의 사건과 인물이 다른 영화로 이어집니다.

이야기는 '페이즈'라는 단위로 묶이고, 여러 페이즈가 모여 하나의 큰 '사가'를 이룹니다. 지금까지 인피니티 사가(페이즈 1~3)가 완결되었고, 멀티버스 사가(페이즈 4~6)가 진행 중입니다.

Project Overview

Behind This Site기획 · 디자인 · 개발 홍어진

영화관의 몰입감과 스트리밍 플랫폼의 정보 구조를 결합해, 보기 좋은 목업이 아니라 실제로 탐색할 수 있는 아카이브를 목표로 만들었습니다.

Design

  • 다크 시네마틱 톤, 레드는 강조에만 사용
  • Bebas Neue · Oswald · Pretendard 타이포 위계
  • 포스터 2:3, 캐릭터 3:4, 배경 16:9 비율 체계
  • 권리 문제 없는 자체 제작 대체 아트워크

Features

  • 검색 + 페이즈 필터 + 정렬 동시 적용
  • 쿼리 파라미터 기반 상세 페이지와 오류 화면
  • LocalStorage 즐겨찾기 (새로고침 후에도 유지)
  • 캐릭터 프로필 모달 (ESC · 바깥 클릭 닫기)

Quality

  • Desktop 4열 · Tablet 3열 · Mobile 2열 그리드
  • 시맨틱 마크업, ARIA, 키보드 탐색, 포커스 표시
  • prefers-reduced-motion 대응
  • 이미지 지연 로딩과 깨진 이미지 대체 처리

Development Skills

HTML5CSS3Vanilla JavaScriptGSAPScrollTriggerSwiper.jsLocalStorageResponsive WebWeb Accessibility
